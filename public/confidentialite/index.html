Politique de confidentialité

La présente Politique de confidentialité décrit comment La Muse Éloquente traite les données personnelles collectées via le Site https://2minpourconvaincre.com.

En utilisant le Site et en communiquant vos données, vous acceptez cette Politique.

Données collectées

Peuvent être collectées :

  • Données d'identité : nom, prénom
  • Coordonnées : adresse e-mail, numéro de téléphone, pays, ville
  • Données liées aux commandes : type de pass, date, montant, référence
  • Données de candidature : informations fournies dans le formulaire, lien vidéo, motivations
  • Données de navigation : adresse IP, navigateur, pages visitées, date et heure
  • Données newsletter : adresse e-mail et préférences de communication

Finalités

Vos données sont utilisées pour :

  • gérer les commandes de pass et les paiements
  • gérer les candidatures au concours
  • vous adresser les informations liées à l'événement (confirmation, rappel, infos pratiques)
  • vous envoyer, avec votre accord, des newsletters et informations sur les prochaines éditions
  • répondre à vos demandes via le formulaire de contact
  • améliorer le Site et mesurer son audience

Base légale

Les traitements sont fondés sur :

  • l'exécution d'un contrat (achat de pass, participation à l'événement, candidature)
  • votre consentement (newsletter, certains champs facultatifs)
  • l'intérêt légitime de La Muse Éloquente (sécurité du Site, amélioration des services)
  • le respect d'obligations légales (facturation, comptabilité)

Destinataires

Les données sont destinées aux équipes habilitées de La Muse Éloquente et à ses prestataires techniques (hébergeur, solution de paiement, e-mailing, billetterie) uniquement pour les besoins des services.

Les données ne sont pas vendues à des tiers.

Durée de conservation

Les données sont conservées pendant la durée nécessaire aux finalités poursuivies, par exemple :

  • données de commande : durée légale de conservation comptable
  • données de candidature : durée de l'édition + archivage raisonnable
  • données newsletter : jusqu'à désinscription
  • données de navigation : durée limitée pour les statistiques

Cookies

Le Site peut utiliser des cookies pour :

  • faciliter la navigation
  • mesurer l'audience
  • améliorer l'expérience utilisateur

Vous pouvez refuser les cookies via les paramètres de votre navigateur. Certains services peuvent alors être dégradés.

Vos droits

Selon la réglementation applicable, vous disposez notamment des droits :

  • d'accès, de rectification, de mise à jour
  • d'effacement (dans les limites légales)
  • de limitation du traitement
  • d'opposition
  • de portabilité (dans certains cas)

Pour exercer vos droits, vous pouvez écrire à contact@2minpourconvaincre.com ou à l'adresse postale : Cinéma Concorde, Cotonou – Bénin.

Une preuve d'identité peut être demandée.

Sécurité

La Muse Éloquente met en œuvre des mesures techniques et organisationnelles raisonnables pour protéger vos données contre l'accès non autorisé, la perte, l'altération ou la divulgation.

Mise à jour

La présente Politique peut être modifiée. La version à jour est celle publiée sur le Site.
